# hypher v2

v2 is not more product. v2 is dump, the packet, writeback. everything else is filler.

bind stays: name + githubRepo. unmatched repo does not mint a project. cursor connect is a door, not a sync.

## keep

- home is dump. one field. paste, file. no greeting token, no checklist, no notion, no digest teaser.
- a project is a name and a githubRepo. human binds it in settings. that list is a binder, not a dashboard. no health rings, no p3, no filters, no generate memory on every card.
- pulse is the packet. three things: latest captures, builder brief (copy), agent updates (writeback). the other eight panels are gone.
- settings is two doors: mint a hyp_ key, connect cursor (oauth so a reader can fetch briefs) plus the repo bind. no digest squatting on keys. no crashing pat theater as the page.
- search stays buried. account stays in the avatar.
